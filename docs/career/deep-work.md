# 深度工作

**结论：** 深度工作的关键是减少上下文切换，而不是单纯延长工时。

## 实践框架

1. **时间块**：为高认知任务预留不被打断的连续时段。
2. **输入管理**：把通知与即时通讯默认静音，批量处理。
3. **收尾仪式**：结束时写下下一步，降低再启动成本。

## 对照表

| 做法 | 效果 |
| --- | --- |
| 多任务并行 | 切换成本高，质量不稳定 |
| 单任务深挖 | 产出更完整，可复盘 |
| 随时响应消息 | 注意力碎片化 |
| 批量处理沟通 | 保留深度时段 |
