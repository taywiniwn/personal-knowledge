# 健康总览

**结论：** 健康管理的目标是「可持续的精力与恢复」，而不是短期极限表现。

## 当前关注面

| 主题 | 说明 |
| --- | --- |
| 睡眠 | 固定起床窗口，优先保护睡眠连续性 |
| 运动 | 以可坚持的频率为主，强度循序渐进 |
| 营养 | 规律进食，减少极端限制 |
| 压力 | 用节奏与边界管理，而不是硬扛 |

## 与数据看板的关系

客观指标（步数、睡眠、心率等）适合写入 `static/data/health/`，由图表页展示。本页保留原则与决策框架，避免把论述写成数字堆砌。

> 示例可改：把本节替换为你真实的健康原则。
