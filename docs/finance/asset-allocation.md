# 资产配置思路

**结论：** 配置解决的是「风险暴露是否可理解、可坚持」，不是追逐单一品种的叙事。

## 原则

1. **先风险预算，后工具选择。**
2. **分散是为了降低单一故事依赖。**
3. **再平衡是纪律，不是择时。**
4. **能坚持的方案优于纸面上更优但执行不了的方案。**
