# 财务总览

**结论：** 财务决策优先服务「长期生存与选择权」，而不是短期相对排名。

## 关注面

| 主题 | 说明 |
| --- | --- |
| 现金流 | 先保证刚性支出与缓冲 |
| 配置 | 用分散与再平衡降低单一冲击 |
| 风险 | 先定义可承受回撤，再谈收益预期 |
| 记录 | 客观数据进 JSON，原则进文档 |

## 数据与叙述分离

量化序列放在 `static/data/finance/`，由 [财务看板](/charts/finance) 渲染。本页只保留原则与框架，避免用具体数字充当论述证据。
