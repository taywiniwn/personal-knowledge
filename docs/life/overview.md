# 人生体验总览

**结论：** 值得记录的体验，是那些改变你「如何看世界」或「如何与人相处」的瞬间。

## 关注面

| 主题 | 说明 |
| --- | --- |
| 旅行 | 用主题与节奏设计，而不是打卡清单 |
| 关系 | 高质量互动优于高频浅层联系 |
| 兴趣 | 允许长期慢培养，不急于变现 |
| 回顾 | 定期把体验沉淀回原则文档 |

## 与其他支柱的关系

人生体验不是孤立栏目：旅行影响健康节律，兴趣可能反哺事业，消费选择关联财务原则。新想法优先融入已有文档。
