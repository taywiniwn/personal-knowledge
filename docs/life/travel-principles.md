# 旅行原则

**结论：** 旅行质量取决于「节奏与主题」，而不是停留天数本身。

## 原则

1. **先定主题**：自然、城市漫游、友人重逢……主题决定行程密度。
2. **留白**：每天保留无计划空隙，让偶发体验发生。
3. **少点深游**：同一区域深入，优于多地跳跃。
4. **事后沉淀**：回来后用几句话写入本库，而不是只留相册。
