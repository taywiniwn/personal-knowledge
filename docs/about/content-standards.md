# 内容标准

宁愿一篇写透，也不要十篇蜻蜓点水。覆盖面广不代表有洞见；浅入深出比面面俱到更有价值。

## 好内容的六条标准

前三条是底线，后三条是追求：

1. **愿意读** — 有明确读者价值，不写成自嗨流水账
2. **读得懂** — 结构清楚，术语有必要解释
3. **能相信** — 观点有因果机制支撑，不堆砌权威感
4. **记得住** — 有可复述的核心句
5. **自带传播力** — 别人转述时仍不失真
6. **可触发行动** — 读完知道下一步可以怎么做

## 信达雅

| 维度 | 要求 | 定位 |
| --- | --- | --- |
| 信 | 忠实于真实认知与事实边界 | 底线 |
| 达 | 表达通畅，读者无需猜作者意图 | 底线 |
| 雅 | 符合阅读习惯，节奏干净 | 追求 |

## 行文约定

- **结论先行**：核心结论先说，再展开细节与例外。
- **正面陈述**：直接说「是什么」，少用「不是……而是……」绕圈子。
- **慎用具体数字作论据**：优先用逻辑关系与因果机制表达观点；需要量化时，把数字放在数据看板或 JSON 源数据中。
- **表格移动友好**：表格优先设计为纵向可读（少列、多行），兼容手机竖屏。

## 示例对比

**不推荐：**

> 某策略在过去三年收益率达到 X%，因此值得长期采用。

**推荐：**

> 该策略的优势来自「降低决策频率 + 分散单一资产冲击」。是否采用取决于你能否接受短期回撤与执行纪律，而不是某一段行情的结果。
