# 关于本站

本站是围绕 **健康、事业、财务、人生体验** 四个方向持续积累的个人知识库。

它不是博客——博客是发布时间点的快照；这里的每篇文档会随认知更新而反复修改。
它也不是笔记——笔记解决了捕获问题，但不解决整合问题；这里每一条新想法都要融入现有结构，而不是追加堆砌。

## 核心原则

| 原则 | 说明 |
| --- | --- |
| 活文档 | 同一篇文档持续修订，页面数量保持克制 |
| 结构由人定 | 目录与支柱由人维护，内容由 LLM 协助填充 |
| 融入而非追加 | 新想法优先并入已有文档，避免页面膨胀 |
| 纯文本友好 | Markdown 存于 Git，便于 AI 读写与审阅 |

## 四大支柱

- [健康](/docs/health/overview) — 身体、睡眠、恢复与可持续节律
- [事业](/docs/career/overview) — 专业成长、深度工作与协作方式
- [财务](/docs/finance/overview) — 资产配置、风险与长期复利思维
- [人生体验](/docs/life/overview) — 旅行、关系与值得记住的体验
